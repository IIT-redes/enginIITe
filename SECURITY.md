# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Do not open a public issue for a security problem. Write to [Pending: contact address of the maintainers] with a description of the problem, the version affected and the steps to reproduce it. You will get an answer as soon as the maintainers can read your report, and the fix will be announced in the [changelog](CHANGELOG.md) once it is released.
